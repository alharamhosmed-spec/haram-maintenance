# بلاغات الصيانة — تطبيق نظام بلاغات الصيانة غير الطبية

غلاف تطبيق (PWA) لـ **نظام بلاغات الصيانة غير الطبية** المبني على Google Apps Script — بنفس «نمط التطبيق» حق بوابة الحرم.
يتثبّت على أندرويد وآيفون والكمبيوتر بأيقونة مفتاح الربط ويفتح بشاشة كاملة على دخول الموظفين مباشرة.

**رابط التطبيق:** `https://alharamhosmed-spec.github.io/haram-maintenance/`

© جميع الحقوق الفكرية محفوظة — مدير إدارة المشاريع: م. أحمد بندر الردادي · مستشفى الحرم

## الإعداد (مرة وحدة)
1. النظام **v2.1.0 أو أحدث** (فيه `setXFrameOptionsMode(ALLOWALL)` ووضع التطبيق `?app=1`).
2. النشر: التنفيذ باسم **أنا** · الوصول **أي شخص**.
3. رابط `/exec` في `index.html` ← `APP_CONFIG.GAS_URL`.

## مزايا
- **يفتح على دخول الموظفين** مباشرة (صفحة رفع البلاغ العامة متاحة من شاشة الدخول).
- **اللوحة التنفيذية مباشرة:** `…/haram-maintenance/?page=dashboard`.
- الجلسة تبقى لين «تسجيل الخروج» أو إغلاق التطبيق.
- التخزين المحلي للغلاف ببادئة `haramMaint_` حتى ما يتداخل مع أي تطبيق ثاني على نفس النطاق.

## التحديثات
- تعديل النظام نفسه: انشره كـ **New version على نفس النشر** — ما تحتاج تلمس GitHub.
- تعديل الغلاف: عدّل الملف وزِد `VERSION` في `sw.js`.
- الأيقونة: `python3 tools/make_icons.py spanner`
